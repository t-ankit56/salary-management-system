# Salary Management System

A web-based salary management system for ACME Organisation, replacing spreadsheet-based
tracking for approximately 10,000 employees across multiple countries.

The system holds employee records, maintains a full history of salary changes over time,
and produces payroll reports for any date — not only the present.

## Status

In development.

## Stack

Django · Django REST Framework · PostgreSQL · React · Docker
